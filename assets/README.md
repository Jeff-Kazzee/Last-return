# Art and source-file handoff

These files were created with the original design document and are available in the ChatGPT conversation. They are **not yet tracked in this GitHub repository**, because the connected text-only GitHub uploader cannot transfer their binary bytes.

Suggested destinations:
- `docs/Last_Return_Game_Design_Document.pdf`
- `docs/Last_Return_Game_Design_Document.docx`
- `assets/concepts/transit_cathedral_paddle_duel.png` — Last Station environment/key-art concept
- `assets/concepts/ruined_cinema_puck_court.png` — overhead cinema-court art concept

Download the source files from the ChatGPT conversation to your machine, then add and commit them from an authenticated Git clone. Do not claim to have uploaded these assets until they appear in the GitHub tree.

Both PNGs are **concept art**, not gameplay screenshots, UV-clean textures, animation sprites, or authoritative level geometry. Maintain readability by extracting deliberate layers and creating collision shapes separately. Curate, edit, and review every final asset; record rights/licensing and provenance before commercial distribution.

Keep large/generated intermediate assets outside Git or use Git LFS with an actual configured storage budget. The four source files above are modest-sized design references, so ordinary Git is acceptable.
